# AMG Tracks Overview (مصفوفة اختيار المسار الإبداعي)

قبل بدء أي مشروع في المرحلة 1، راجع هذه المصفوفة لاختيار المسار الأمثل لطبيعة المحتوى:

| المسار | الهوية البصرية | الأنسب لـ | التقنيات والموارد المربوطة |
| :--- | :--- | :--- | :--- |
| **`01-editorial-vox-explainer`** | ورق تحريري دافئ، تظليل نصي، شبكة هندسية | مقالات صحفية، تحقيقات، شروحات علمية | `diagram-design` + `lucide` + `highlighterSweep` |
| **`02-flagship-product-launch`** | أسود سينمائي، إضاءة درامية، بطاقات Bento | إطلاق منتجات SaaS، تقنيات حديثة، إعلانات فاخرة | `satori` + `video-shotcraft` + `simple-icons` |
| **`03-isometric-system-anatomy`** | منصات وشبكات ثلاثية الأبعاد، تفكيك طبقي | معمارية سحابية، أنظمة ذكاء اصطناعي، أجهزة | `wheresryan22/anatomy` + `tabler-icons` |
| **`04-dynamic-data-journalism`** | خطوط وأعمدة متحركة، عدادات، تحول بياني | تقارير مالية، إحصائيات اقتصادية، بيانات ضخمة | `d3/d3` + `odometerCounter` + `RacingBarChart` |
| **`05-kinetic-typography-reels`** | ألوان نيون جريئة، إيقاع سريع (9:16) | ريلز إنستغرام، تيك توك، إعلانات خاطفة | `iart-ai/motion-skills` + `Beat-Sync` |
| **`06-ad-breakdown-hyperframes`** | أبيض وأسود، تحليل إيقاع إعلاني، مقارنة | دراسة وتحليل الإعلانات وتطوير المسودات | `blixvip/NullMotion` + `HyperFrames` |
| **`07-arabic-editorial-motion`** | موشن عربي أصيل، خطوط ثمانية، اتجاه RTL | وثائقيات عربية، بودكاست، محتوى إنفوجرافيك | `amg-text-engine` (RTL) + `خطوط عربية مدمجة` |
